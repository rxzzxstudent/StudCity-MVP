# Nooki WebApp & Telegram Serverless Bot ⚡

Frontend & API Webhook для сервиса **Nooki** на Next.js 14 и Vercel.

## 📦 Скрипты
- `npm run dev` — Запуск локального сервера разработки.
- `npm run build` / `npm run validate` — Сборка проекта под Vercel.
- `npm run setup-bot` — Настройка и регистрация Telegram Webhook.
