## Важное обновление: Переход от StudCity к Nooki

Команда проекта провела стратегический ребрендинг и масштабирование:
- Первоначальная концепция StudCity была сфокусирована исключительно на студенческой аудитории вокруг университетских кампусов.
- В ходе валидации гипотез и тестирования мы расширили продукт до **Nooki** — единого городского сервиса для всех жителей и гостей Алматы (горожан, офисных сотрудников, фрилансеров и студентов).
- Проблема поиска выгодных предложений на обеды, спорт и услуги в «тихие часы», а также потребность в навигаторе по городской инфраструктуре (Wi-Fi, розетки для зарядки, санузлы) актуальна для всего города Алматы.

Nooki — двусторонняя цифровая экосистема динамического ценообразования для локального бизнеса и бесплатная карта городской инфраструктуры для всех жителей города.

Сервис позволяет заведениям заполнять непиковые часы клиентами со скидками до 50% без риска для основного чека, а горожанам — экономить и находить проверенные места с Wi-Fi, розетками и санузлами.

## Реализованные функции

### Клиентский интерфейс B2C
- **Каталог Flash-слотов:** Просмотр предложений заведений с обратным отсчетом тихих часов и счетчиком остатка мест.
- **Динамический 4-значный PIN-код:** Генерация защищенного одноразового кода на скидку со сроком действия 300 секунд (5 минут) без привязки банковских карт.
- **Интерактивная карта инфраструктуры (Survival Map):** Поиск городских точек с фильтрацией по категориям: санузлы, розетки для зарядки устройств, скоростной Wi-Fi, зоны для тихой работы и заведения со скидками.
- **Адаптация PWA и Telegram Mini App:** Полнофункциональная работа на десктопных устройствах, мобильных браузерах и внутри Telegram-клиента.

### Интерфейс партнера B2B
- **Веб-терминал Кассы:** Быстрая верификация и списание 4-значного PIN-кода гостя за 3 секунды без покупки отдельного оборудования и без интеграции с кассовыми системами.
- **Конструктор скидки:** Управление параметрами слота:
  - Размер скидки (от 10% до 60%);
  - Smart Cap — дневной лимит мест (от 5 до 50 слотов в день для предотвращения перегрузки персонала);
  - Временное окно тихих часов;
  - Интерактивный предпросмотр карточки заведения в режиме реального времени.
- **Тумблер управления акцией:** Мгновенная деактивация и активация специального предложения одной кнопкой при высокой загрузке заведения.
- **Аналитика непикового спроса:** Просмотр показателей пешеходного трафика, пиков поиска и среднего чека района.
- **Ролевое разграничение прав:** Раздел кассы доступен только авторизованным бизнес-аккаунтам. Для аккаунтов заведений заблокирована возможность оформления клиентских скидок.

## Стек технологий

| Категория | Технологии | Назначение |
| :--- | :--- | :--- |
| **Frontend** | Next.js 14 (App Router), React 18, TypeScript | Архитектура веб-приложения, строгая типизация |

## Использованные AI-инструменты

1. **Google DeepMind Antigravity AI IDE:**
   - Проектирование архитектуры реактивного клиентского состояния (AppContext) для синхронизации таймеров тихих часов, конструктора скидок и реестра кодов.
   - Оптимизация сборки под квоты Vercel Free Tier с помощью динамических импортов (React.lazy / dynamic), сократившая размер первичного бандла до 180 КБ First Load JS при лимите 500 КБ.
   - Отладка и предотвращение конфликтов жизненного цикла компонентов React.
2. **Claude 3.5 Sonnet и Gemini Pro:**
   - Формирование архитектурных моделей данных TypeScript.
   - Разработка схемы реляционной базы данных PostgreSQL с политиками безопасности Row Level Security (RLS).
   - Формирование продуктовых и маркетинговых сценариев взаимодействия B2C и B2B.
3. **Генеративные инструменты визуализации:**
   - Разработка векторной символики бренда Nooki Loop в формате SVG и конвертация медиаресурсов в формат WebP.

## Быстрый запуск

### 1. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com/rxzzxstudent/StudCity-MVP.git
cd StudCity-MVP
npm install
```

### 2. Запуск сервера разработки
```bash
npm run dev
```
Приложение доступно по адресу: http://localhost:3000

### 3. Проверка типов и сборка
```bash
npm run build
```
